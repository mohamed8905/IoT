## 📂 Contents

- **Source Code:**  
  Practical IoT applications using C++ with PlatformIO.
- **Platform:**  
  Developed for the ESP32 microcontroller (esp32dev board) using the Arduino framework.
- **Dependencies:**  
  - [ESP32Servo](https://platformio.org/lib/show/11689/ESP32Servo)
  - [LiquidCrystal_I2C](https://platformio.org/lib/show/5761/LiquidCrystal_I2C)
  - [PubSubClient](https://platformio.org/lib/show/89/PubSubClient)
  - [ArduinoJson](https://platformio.org/lib/show/64/ArduinoJson)
  - [ESPSupabase](https://platformio.org/lib/show/15142/ESPSupabase)
  - [DallasTemperature](https://platformio.org/lib/show/54/DallasTemperature)

  *(View all dependencies and config in [`Project/platformio.ini`](https://github.com/mohamed8905/IoT/blob/main/Project/platformio.ini))*

## 🚀 Highlights

- Real-world IoT programming exercises.
